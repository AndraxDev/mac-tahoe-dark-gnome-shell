# MacTahoe modified theme

Original theme is located at: https://github.com/vinceliuice/MacTahoe-gtk-theme

# Changes made to the original theme:

- Optimized for Ubuntu 26.04 and Gnome 50.
- Redesigned thw quick settings panel.
- Minor changes to the notification panel.
